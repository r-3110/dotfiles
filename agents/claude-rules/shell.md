# Shell

- 変数展開とパスは、意図的に単語分割する場合を除いて引用する。
- 外部入力を `eval`、`sh -c`、文字列結合したコマンドへ渡さない。
- 一時ディレクトリには `mktemp -d` を使い、終了時の後始末を考慮する。
- 破壊的操作の対象に、未検証の環境変数、glob、コマンド置換を使わない。
- スクリプトの変更後は、利用可能なら構文検査と `shellcheck` を実行する。
- 使用するシェルで挙動が異なる構文は、対象シェルを明記する。
